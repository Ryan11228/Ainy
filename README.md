# 🪄 My Wizarding Portfolio

A Harry Potter-inspired portfolio website, built as my first coding project to learn **HTML, CSS, JavaScript and TypeScript**. It's a personal learning project and a fan-made tribute, not an official portfolio.

## ✨ Features

- 🕯️ Floating candles and a sparkle cursor trail
- 🏰 Four house themes (red/gold, green/silver, blue/bronze, yellow/black)
- 💡 **Lumos / Nox** light and dark mode (remembers your choice)
- 🎩 **Sorting Hat** button that picks a random house
- 🔍 **Accio** search to filter projects
- 📜 Scroll animations and a timeline styled like the Marauder's Map
- 📱 Responsive on phone, tablet and desktop
- 🖼️ Images load from links, so they're easy to swap

## 🛠️ Built With

- HTML5
- CSS3 (variables, grid, animations)
- JavaScript (ES modules)
- TypeScript
- Google Fonts: Cinzel, IM Fell English, Inter

## 📁 Project Structure

```
├── index.html               # page skeleton
├── package.json
├── tsconfig.json
├── src/
│   ├── config/
│   │   └── site.config.ts   
│   ├── ts/
│   │   ├── main.ts          # starts everything
│   │   ├── render.ts        # puts content into the page
│   │   ├── effects.ts       # candles, sparkles, scroll reveal
│   │   └── types.ts         # data checklists
│   └── styles/
│       └── style.css        # all the looks
└── dist/                    # compiled JavaScript (auto-generated)
```

## 📚 What I Learned

- Structuring a project with HTML, CSS and TypeScript
- Using CSS variables for themes
- Splitting code into ES modules
- Using TypeScript types to catch mistakes early
- Handling events, DOM updates, `localStorage` and the IntersectionObserver
- Publishing a static site with GitHub Pages
